# Cadmus-Scan

Partie logicielle du projet **Cadmus**, issue de l'évolution de **Gryphon Scan**.

Ce dossier accueillera le code du logiciel de scan 3D, sa migration vers Python 3.12, les tests automatisés et sa documentation.

Les notices d'origine et la licence GPL-2.0 du code Gryphon Scan devront être conservées lors de son intégration.

La partie matérielle est regroupée dans [Cadmus-Scanner](../Cadmus-Scanner/).
