# Cadmus

Projet de scanner 3D et de logiciel de numérisation.

- [Cadmus-Scan](Cadmus-Scan/) : logiciel issu de Gryphon Scan, migration en cours
  vers Python 3.13 et NumPy 2.1.
- [Cadmus-Scanner](Cadmus-Scanner/) : conception mécanique, électronique et
  documentation du scanner.

Le logiciel n'est pas encore validé pour un scan complet sur matériel réel.
