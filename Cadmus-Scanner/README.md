# Cadmus-Scanner

Partie matérielle du projet **Cadmus** : le scanner 3D.

Ce dossier accueillera les fichiers de conception mécanique, les schémas électroniques, la nomenclature et les instructions d'assemblage et de réglage.

La partie logicielle, issue de Gryphon Scan, est regroupée dans [Cadmus-Scan](../Cadmus-Scan/).
